# AI Voice Assistant – Real-Time, Smart & Interactive
Ever wanted to build your own AI-powered voice assistant? <br>
This project brings that idea to life using Python, Google Generative AI, Flask, and JavaScript — all working together to create a real-time voice assistant that can listen, think, and respond intelligently.

## What This Project Does
✅ Listens to your voice commands in real time  <br>
✅ Sends input to Google AI for smart, human-like responses   <br>
✅ Shows a dynamic conversation history right on the web page  <br>
✅ Runs on a lightweight Flask web app you can easily deploy  <br>

## What You’ll Learn
How to capture and process speech using Python   <br>
How to connect with Google’s Generative AI for responses   <br>
How to use Flask & JavaScript for live updates   <br>
How to build and deploy an interactive AI web app <br>
By the end, you’ll have your very own personal AI voice assistant — an impressive, hands-on project perfect for your portfolio or next AI experiment!  <br>
