# AI Voice Assistant – Real-Time, Smart & Interactive
Ever wanted to build your own AI-powered voice assistant?
This project brings that idea to life using Python, Google Generative AI, Flask, and JavaScript — all working together to create a real-time voice assistant that can listen, think, and respond intelligently.

## What This Project Does
✅ Listens to your voice commands in real time
✅ Sends input to Google AI for smart, human-like responses
✅ Shows a dynamic conversation history right on the web page
✅ Runs on a lightweight Flask web app you can easily deploy

## What You’ll Learn
How to capture and process speech using Python
How to connect with Google’s Generative AI for responses
How to use Flask & JavaScript for live updates
How to build and deploy an interactive AI web app
By the end, you’ll have your very own personal AI voice assistant — an impressive, hands-on project perfect for your portfolio or next AI experiment!
